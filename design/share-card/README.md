# Link-preview image

`index.html` is the artwork for the picture that appears when the site is
texted or posted (the Open Graph / Twitter card image). The published file is
`src/images/share-card.jpg`, a 1200 x 630 screenshot of this page.

If the names, date or venue change:

1. Edit the wording in `index.html`.
2. Open it in a browser window sized to 1200 x 630 and save a screenshot over
   `src/images/share-card.jpg` (or ask Claude to "regenerate the share card").

Messaging apps cache previews, so an updated image can take a while to show
for links that have already been shared.
