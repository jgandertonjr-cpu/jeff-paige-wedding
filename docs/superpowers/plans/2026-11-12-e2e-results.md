## Cost

A request sends about 27,400 tokens of instructions and site content. The first
request in any five-minute stretch costs about 7 cents; follow-up requests
within five minutes reuse the cached content and cost under 1 cent each. A
bigger change that reads the stylesheet costs roughly 10–15 cents. The whole run
above (about 22 model calls) cost well under $1. Exact billing is on the
Anthropic console's usage page.

## What the run showed needs changing

1. **Year questions.** Request 1 asked which year. With the wedding date on the
   site, the editor should assume the year that fits and show it in the summary.
2. **Giving up too early on look changes.** Request 16's first answer said it
   couldn't change button shapes; it can. It should read the stylesheet before
   saying no.
3. **An emoji in a reply** (request 15). The site's style has none.
4. **Summary of a small edit inside long text.** Request 3's line showed the
   same opening words before and after, so the change was not visible in the
   summary (the note explained it).
5. **History titles cut in the wrong place.** Request 2's title was cut at
   "Details (ceremony, reception, schedule) → Ceremony → Ceremony details →",
   losing the part that says what changed.
6. **Request 16 produced 8px corners**, which goes beyond the square 3px
   buttons in `DESIGN.md`. The editor allowed it because the owner asked, showed
   it as a bigger change and required a preview. Noted for Jeff's judgement, not
   treated as a defect.
