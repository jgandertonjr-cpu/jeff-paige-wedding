# Fonts

Self-hosted copies of the site's three typefaces, all under the SIL Open Font
License 1.1 (free to use, embed and redistribute).

| File | Typeface | Notes |
|---|---|---|
| `cormorant-garamond-latin.woff2`, `-latin-ext.woff2` | Cormorant Garamond, upright | variable, weights 300–700 |
| `cormorant-garamond-italic-latin.woff2`, `-latin-ext.woff2` | Cormorant Garamond, italic | variable, weights 300–700 |
| `jost-latin.woff2`, `-latin-ext.woff2` | Jost | variable, weights 300–600 |
| `pinyon-script-ampersand.woff2` | Pinyon Script | contains only the "&" |

They are declared in `@font-face` rules at the top of `src/css/styles.css`.
The files came from Google Fonts (fonts.google.com), which is where to get
fresh copies if a typeface is ever swapped.
